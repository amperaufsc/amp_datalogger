# Datalogger

A data logger is a system responsible for collecting, recording, and storing data from sensors and other devices over time. It is widely used in industrial, automotive, and embedded applications for system monitoring, analysis, and diagnostics.
In this project, communication between modules is carried out via the CAN (Controller Area Network) bus, a robust and reliable protocol widely used in embedded systems to allow real-time data exchange between various devices, even in environments subject to electrical noise.
The system reads and acquires data from the sensors, processes the information received via CAN or direct inputs, and then saves the data in an organized and persistent manner. This data can later be used for analysis, fault tracking, performance validation, or report generation.
